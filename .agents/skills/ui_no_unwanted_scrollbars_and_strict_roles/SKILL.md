# التزام صارم بجماليات الواجهة والحفاظ على الأدوار والصلاحيات

تطبيق التوجيهات التالية لجميع التعديلات المستقبلية على منصة سكن:

1. **إخفاء أشرطة التمرير غير المطلوبة (No Unwanted Scrollbars):**
   - يمنع ظهور أشرطة التمرير الأفقية التي تخرب مظهر الصفحة.
   - عند الحاجة للتمرير، يجب إخفاء شريط التمرير بأسلوب احترافي باستخدام CSS (`[scrollbar-width:none] [-ms-overflow-style:none] [&::-webkit-scrollbar]:hidden`).

2. **الحفاظ الصارم على جميع الأدوار (Strict Role Integrity):**
   - يمنع إخفاء أو حذف أي دور من الأدوار الأساسية في النظام (`executive`, `project_manager`, `employee`, إلخ) عند تنسيق الجداول.
   - التعديل يكون على التصميم والمظهر فقط دون المساس بهيكل البيانات أو الأدوار.

3. **لغة عربية كاملة وبدون شرح:**
   - الالتزام التام باللغة العربية دون مصطلحات إنجليزية.
   - الإجابة تكون بطلب التنفيذ المباشر ودون كتابة شروحات وتبريرات.
